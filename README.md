# scripting-for-cybersecurity
This repository contains my practical work for the Scripting for Cybersecurity module.
short description: To provide learners with a theoretical
knowledge and the practical skills to
automate cybersecurity tasks such as
network traffic manipulation and Web
application and network infrastructure
fingerprinting.
## Labs
- Lab 01 - Development Environment
- Lab 02 - Linux Command Line
- Lab 03 - Text processing and log analysis
- Lab 04 - Finding files and working with data
- Lab 05 - From commands to scripts - shebangs, variables and input
